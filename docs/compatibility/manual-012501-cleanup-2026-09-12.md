# Offline execution compatibility: corrected observations

This reference describes a captured offline comparison. Complete payload
equality was **not achieved**. The baseline and corpus boundaries are in
[the input comparison](manual-012501-differences-2026-09-12.md).

## Reference and provenance

Frozen Chrome **152.0.7977.82**, Chromium
`d04cdb24d67b081f6cf80200ffc5233f44b61109`, V8 `15.2.124.21`;
executable SHA256:
`ea36dd818a90176f1a70616f0363d9be527229389a6c073a0b1688b9e73f67e9`.

Two controls used ordinary fresh profiles, headful Chrome, a fixed nonzero
debugging port, no separate incognito Context and no webdriver overrides.
Both observed the original navigator.webdriver=false before navigation.
Each recorded ten complete serializer pairs, ten exact matches to following
POST bodies, no harness errors and no parse errors.

These are **intercepted offline controls**: the unchanged 39-response corpus,
proxy/DNS/UDP restrictions and blocked live-service access define the boundary.
Recorded navigation/server outcomes cannot establish live acceptance. Earlier
port-zero diagnostics remain separate. Changing launch/profile conditions did
not change the targeted IGBuA2, oHIQ6, SbVZ3, BMnw0/knVv1 or four hash values;
this does not establish timing, routing or general profile equivalence.

Private evidence is in `.build/cleanup-012501/`, including
`chrome-profile-{a,b}/result.json`, `comparison-summary.json`,
`residual-classification.json` and `final-receipt.json`. The source baseline
is `9c82cddc6a564de1a38c285c566fc30107f21064`; source manifests and the patch
digest identify the measured changes beyond it. Receipts retain exact buildInfo,
executable/source/capture hashes for `mimic.exe` and `offline-replay.exe`.

Effective scale, hinting and transformed glyph bounds require separate controls.

## Recorded validation status

These results apply to the source/binaries identified by `final-receipt.json`,
not a later checkout.

- Focused ordinary/snapshot regressions passed. Recorded full non-race suites
  also passed, including the encoding-corrected build (browser 283.546 seconds).
- The first full race suite reached its ten-minute timeout. A 30-minute retry
  ended after 1427 seconds with a visible-shadow-frame failure in an earlier SVG
  implementation. The corrected focused oracle passed, but a full race PASS on
  final source was **not established**.
- A wider focused race check hit a Goja deadline in
  TestFrameInsertionAfterInnerHTMLAndFragmentMove. That test and all new execution
  regressions passed on the final executable in 13.141 seconds. No DATA RACE
  reports were recorded; this is not a full race pass.
- Final replay has ten complete pairs, ten exact POST-body matches and no parse
  errors. Ten error-value leaves in the API table are observations, not parse
  failures.
- Original `.build/analysis-012501/receipt.json` hashes were rechecked;
  `git diff --check` passed.

Wire performance and external-server acceptance were not measured.

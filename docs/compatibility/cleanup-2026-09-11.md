## Implementation

Generated WebIDL installation now links interface objects to their parent
interface objects after all exposed declarations exist. It already linked
instance prototypes; static inheritance and reflection now agree with that chain
and remain realm-local. This closes original group `7ce0490158dc72b8` and three
complete fixed probes. It does not add APIs or alter unsupported method bodies.

DOMException now constructs its Error-backed instance independently of its public
constructor chain. Its prototype still inherits Error.prototype, while the
interface object inherits Function.prototype, as measured in Chrome.

The broad sweep caught an intermediate regression: XMLHttpRequest's handwritten
constructor skipped XMLHttpRequestEventTarget, so installing the correct public
chain routed super() into an unsupported generated constructor. A real intermediate
interface now performs internal EventTarget initialization; its public constructor
remains illegal. The new oracle covers XHR creation/brand/state as well as main,
child and restored-realm inheritance. The failed intermediate sweep and aborted
superseded full test run remain in the receipts; neither is a final pass.

The generated artifact manifest also lacked the four order artifacts and carried
the stale exposure-data hash from `037f8ff`. It was refreshed against the existing
tracked artifacts plus this regenerated surface; no order expectation changed.
